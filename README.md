# Beauty-Parlour
A frontend parlour website created using html, css and javascript. Thats helps to grow a beauty parlour online, connects with clients and show their work publicly with sections like Home where you will get a overview of the parlour, About section more description about parlour, Service section helps show which services the parlour provides and more like styles, pricing and also you can direct book a visit to the parlour from this website and also there is a review section you can verify how the parlour worked before and also you can share your experience there.
